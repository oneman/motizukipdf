symbol that is not an English letter (†, ‡, ∗, ◦, •, ⊢, ⊩, ▶, ×, μ, ⊥, ±, ⋊, ⊞, ⊚, ⊛, Δ, >, ∞, …)

case-insensitively, so they can be used as C identifiers, JS keys, file names and URL fragments.

## Species and mutations ([IUTchIV] §3)

A *species* is a set-theoretic formula defining a type of mathematical object; a
*mutation* is a species-theoretic functor; the log-theta-lattice is a *mutation-history*
([IUTchIV] Def. 3.1, 3.3). The program implements each species as a C struct and each
mutation as a function.
